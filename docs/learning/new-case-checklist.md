# 新規ケースチェックリスト

1. 学習用・実対象と実行先を識別し、専用DBと所有範囲を確認する。
2. `tests/scenarios/` の対象分類へケースを追加し、固定fixtureと期待HTTP・画面・DBを先に決める。
3. Given／When／Then／Afterを `test.step` で明示し、件数・キー・値・関連を照合する。
4. モックやデータの変更前状態を退避し、途中失敗時も復元・確認、プロセス終了を回収する。
5. 照合器に欠落・重複・余剰・値・関連・削除漏れを注入し検出を確認する。
6. 秘密・巨大本文を証跡へ出さず、PASS／FAIL／未確認と復元状態を別に残す。共有DB・実AWS・SSOは別途許可と環境確認が必要。
